# 微信记忆翻牌消除小游戏界面设计线框图

## 设计目标

- 第一屏直接进入可玩体验，减少说明文字。
- 核心玩法界面保持干净，牌阵不被广告、弹窗或复杂按钮遮挡。
- IAA 广告入口放在玩家主动决策点：结算、提示、复活、额外奖励。
- 所有按钮区域适配手机触摸，底部主按钮优先，顶部放轻量状态和工具。

## 首页

用途：展示游戏主入口、继续关卡、金币/提示数量、轻量广告入口。

```text
┌────────────────────────────┐
│  金币 128        ⚙ 设置     │
│                            │
│        翻牌消消乐          │
│      轻松找对子，通关领奖   │
│                            │
│      ┌────────────────┐    │
│      │    继续第 8 关   │    │
│      └────────────────┘    │
│                            │
│      ┌────────────────┐    │
│      │     关卡选择     │    │
│      └────────────────┘    │
│                            │
│  ┌────────┐  ┌────────┐    │
│  │ 免费金币 │  │ 每日奖励 │    │
│  └────────┘  └────────┘    │
│                            │
│········ Banner 预留区 ·····│
└────────────────────────────┘
```

交互说明：

| 元素 | 行为 |
| --- | --- |
| 继续第 N 关 | 进入当前进度关卡 |
| 关卡选择 | 打开关卡选择页 |
| 免费金币 | 可接激励视频，完成后发放金币 |
| 每日奖励 | 领取普通奖励，后续可加广告翻倍 |
| 设置 | 打开设置弹窗 |
| Banner 预留区 | 第 5 期再启用，首页底部展示 |

## 提示不足弹窗

用途：玩家主动触发激励视频广告的主要入口之一。

```text
┌────────────────────────────┐
│          提示不足           │
│                            │
│   看一段视频，免费获得提示   │
│                            │
│      ┌────────────────┐    │
│      │   看视频拿提示   │    │
│      └────────────────┘    │
│                            │
│      ┌────────────────┐    │
│      │      暂时不用    │    │
│      └────────────────┘    │
└────────────────────────────┘
```

广告规则：

| 状态 | 处理 |
| --- | --- |
| 完整观看 | 发放 1 次提示并立即高亮一对牌 |
| 中途关闭 | 不发放提示，回到关卡 |
| 加载失败 | 提示稍后再试，不消耗次数 |

## 新手引导

MVP 可用轻量遮罩提示，不需要长教程。

```text
┌────────────────────────────┐
│  步数 00      用时 00:00    │
│                            │
│       ┌────┐┌────┐          │
│       │ ?? ││ ?? │          │
│       └────┘└────┘          │
│          ▲                 │
│          │                 │
│      点两张牌，找到相同图案  │
│                            │
│          我知道了           │
└────────────────────────────┘
```

触发策略：

| 关卡 | 引导 |
| --- | --- |
| 第 1 关 | 提示点击两张牌 |
| 第 1 次匹配失败 | 提示记住位置 |
| 第 1 次匹配成功 | 提示相同牌会消除 |
| 第 2 关以后 | 不再强制引导 |

## 关卡页适配规则

| 屏幕区域 | 设计要求 |
| --- | --- |
| 顶部 | 只放返回、关卡名、暂停、步数、用时 |
| 中部 | 牌阵居中，保留足够点击间距 |
| 底部 | 放提示和重开，不放 Banner |
| 刘海屏 | 顶部状态栏增加安全区 |
| 小屏手机 | 优先缩小卡牌间距，不压缩按钮文字 |
| 横屏 | 暂不作为 MVP 目标，优先竖屏 |

## 视觉风格建议

- 牌面主题优先选择水果、表情或日常物品，识别度高。
- 卡背使用统一图案，避免和正面图案混淆。
- 成功反馈用亮色高亮和轻微缩放，失败反馈用短暂停留，不要强烈惩罚感。
- 首页和结算页可以更活泼，关卡页保持清爽。
- 广告按钮文案必须说明收益，例如“看视频双倍 +60”“看视频拿提示”。
