# 微信记忆翻牌消除小游戏玩法设定

## 玩家幻想

玩家像在一张小桌面上快速寻找成对卡牌，通过记忆位置、连续匹配和清空牌阵获得轻松的成就感。游戏不强调高压失败，第一版重点是短局、顺滑、容易再来一关。

## 玩法概述

游戏是一款记忆翻牌消除类微信小游戏。关卡中所有卡牌初始盖住，每两张牌拥有相同图案。玩家每次翻开两张牌，如果图案相同则消除，如果不同则短暂展示后重新盖住。全部卡牌消除后通关。

## 核心规则

- 每个关卡包含偶数张卡牌。
- 卡牌按两两相同成对生成。
- 每次最多允许翻开两张未消除卡牌。
- 两张牌 `pairId` 相同则匹配成功并消除。
- 两张牌 `pairId` 不同则匹配失败，延迟后盖回。
- 全部卡牌进入 `removed` 状态时关卡完成。
- 普通模式第一版设置失败条件：超过当局时长，或错配次数超过设定上限。

## 第一版标准关卡

| 项目 | 设定 |
| --- | --- |
| 牌阵 | 4x4 |
| 卡牌数量 | 16 张 |
| 配对数量 | 8 对 |
| 模式 | 普通模式 |
| 通关条件 | 消除全部卡牌 |
| 失败条件 | 超过当局时长，或错配次数超过设定上限 |
| 单局时长目标 | 60-120 秒 |
| 默认时长上限 | 120 秒 |
| 默认错配上限 | 12 次 |

## 单局流程

1. 玩家进入关卡。
2. 系统根据 `LevelConfig` 选择 8 个图案。
3. 每个图案生成两张牌并随机打乱。
4. 所有卡牌先以正面状态展示 2 秒，让玩家短暂记忆牌型，这个状态下，牌是不可以点击的。
5. 2 秒预览结束后，所有未消除卡牌统一翻回背面。
6. 玩家点击第一张牌，卡牌翻开。
7. 玩家点击第二张牌，卡牌翻开。
8. 系统进入匹配判断状态。
9. 匹配成功则播放反馈并移除两张牌。
10. 匹配失败则失败次数 +1，展示一小段时间后盖回。
11. 系统持续检查当局时长和失败次数是否超过关卡限制。
12. 如果超过当局时长，或失败次数超过设定上限，则关卡失败。
13. 如果全部卡牌消除，则关卡通关。
14. 结算页展示用时、步数、失败次数、星级和奖励。
15. 玩家进入下一关、重玩，或观看广告获得额外奖励。

## 操作方式

| 操作 | 行为 |
| --- | --- |
| 点击卡牌 | 翻开未消除、未锁定的卡牌 |
| 点击提示 | 消耗提示道具或观看激励视频，高亮一对可消除牌 |
| 点击暂停 | 暂停计时和输入 |
| 点击重玩 | 重置当前关卡并重新洗牌 |
| 点击下一关 | 进入下一关配置 |

## 游戏状态机

| 状态 | 说明 | 可接受输入 |
| --- | --- | --- |
| `ready` | 关卡已生成，准备展示开局预览 | 不接受牌面点击 |
| `previewing_cards` | 所有卡牌正面展示 2 秒，供玩家记忆 | 不接受牌面点击 |
| `idle` | 等待玩家翻牌 | 点击卡牌、暂停、提示 |
| `first_card_opened` | 已翻开第一张牌 | 点击第二张不同卡牌 |
| `checking_match` | 已翻开两张牌，系统判断中 | 不接受牌面点击 |
| `resolving_match` | 匹配成功并执行消除 | 不接受牌面点击 |
| `resolving_mismatch` | 匹配失败并等待盖回 | 不接受牌面点击 |
| `level_complete` | 全部消除，等待结算 | 下一关、重玩、广告奖励 |
| `paused` | 暂停或广告播放中 | 恢复、退出 |

## 卡牌状态

| 状态 | 说明 |
| --- | --- |
| `face_down` | 背面朝上，可点击 |
| `face_up` | 正面朝上，等待匹配 |
| `locked` | 正在动画或判断，不可点击 |
| `removed` | 已消除，不可点击 |

## 计分和表现指标

第一版不建议使用复杂分数公式，优先使用容易理解的步数、用时和星级。

| 指标 | 说明 |
| --- | --- |
| 步数 | 每翻开两张牌记为 1 步 |
| 用时 | 从第一张牌翻开到全部消除的时间 |
| 失败次数 | 每次两张牌未成对时 +1 |
| 剩余失败次数 | `maxMismatchCount - mismatchCount` |
| 连击 | 连续匹配成功次数 |
| 星级 | 根据步数和用时综合计算 |
| 金币 | 通关后按星级发放 |

## 星级规则

每关独立配置星级阈值。第一期可先按步数计算，第二期加入时间维度。

| 星级 | 条件示例 |
| --- | --- |
| 3 星 | 步数不高于优秀阈值，且用时不高于优秀阈值 |
| 2 星 | 步数或用时不高于普通阈值 |
| 1 星 | 完成关卡但超过普通阈值 |

4x4 标准关建议初始阈值：

| 星级 | 步数建议 |
| --- | --- |
| 3 星 | 12 步以内 |
| 2 星 | 18 步以内 |
| 1 星 | 完成即可 |

## 胜利、失败和恢复

| 模式 | 胜利条件 | 失败条件 | 恢复方式 |
| --- | --- | --- | --- |
| 普通模式 | 限定时间内消除全部卡牌，且错配次数未超过上限 | 超过当局时长，或错配次数超过上限 | 重玩；后续可看激励视频复活 |
| 限时模式 | 倒计时结束前全部消除，且错配次数未超过上限 | 时间归零，或错配次数超过上限 | 看激励视频增加时间或复活 |
| 限步模式 | 步数耗尽前全部消除，且错配次数未超过上限 | 步数为 0 且仍有未消除牌，或错配次数超过上限 | 看激励视频增加步数或复活 |

## 道具、奖励和广告关联

| 道具/能力 | 获取方式 | 效果 | 广告关联 |
| --- | --- | --- | --- |
| 提示 | 金币购买、每日奖励、激励视频 | 高亮一对可消除牌 | 主要激励广告位 |
| 双倍奖励 | 通关后观看激励视频 | 通关金币翻倍 | 主要激励广告位 |
| 增加时间 | 限时关观看激励视频 | 增加 30 秒 | 中期加入 |
| 增加步数 | 限步关观看激励视频 | 增加 3-5 步 | 中期加入 |
| 失败复活 | 失败后观看激励视频 | 继续当前关卡 | 中期加入 |

## 关卡模式

| 模式 | 说明 | 上线阶段 |
| --- | --- | --- |
| 普通模式 | 有时长和错配次数限制，消除全部卡牌即可通关 | 第一期 |
| 限时模式 | 在限定时间内完成 | 第 4 期 |
| 限步模式 | 在限定步数内完成 | 第 4 期 |
| 特殊牌模式 | 加入锁定牌、遮挡牌、奖励牌或干扰牌 | 后续扩展 |

## 难度递进

| 难度维度 | 示例 |
| --- | --- |
| 牌阵规模 | 2x2、3x4、4x4、5x4、6x4 |
| 配对数量 | 2 对、6 对、8 对、10 对、12 对 |
| 阈值收紧 | 星级步数和用时逐步提高要求 |
| 模式变化 | 普通模式后加入限时和限步 |
| 图案相似度 | 后期使用更相近的图案提升记忆难度 |
| 翻回延迟 | 后期缩短错误匹配展示时间 |

## 反馈表现

- 翻牌：点击后 3D 或 2D 翻转，展示正面图案。
- 匹配成功：卡牌高亮、缩放、淡出或飞走。
- 匹配失败：短暂停留后翻回背面。
- 连击：连续匹配时显示轻量连击提示。
- 通关：星级动画、金币飞入、下一关按钮。
- 提示：短暂高亮一对可消除牌，不直接替玩家消除。
- 音效：翻牌、匹配成功、匹配失败、通关、奖励。
- 震动：匹配成功和通关可使用微信轻震动。

## 边界情况

- `checking_match` 状态下禁止继续点击卡牌。
- 已消除卡牌不可再次点击。
- 同一张牌不能作为第一张和第二张。
- 只有两张牌未成对时才增加失败次数，点击无效牌或重复点击不计入失败次数。
- 失败次数达到上限时可继续最后一次盖回动画；超过上限后进入失败结算。
- 当局时长超过 `levelTimeLimitSeconds` 时，立即停止输入并进入失败结算。
- 广告播放期间进入 `paused`，暂停计时和输入。
- 广告关闭或失败不发奖励，也不消耗道具。
- 关卡重开必须重新洗牌。
- 每次进入或重开关卡都应重新执行 2 秒正面预览。
- 开局预览期间不计入用时，不允许点击卡牌、提示或重开。
- 快速连续点击只能生效一次，避免状态错乱。

## 平衡性测试

- 每 10 个关卡检查平均通关步数，避免难度突然跳升。
- 新手前 5 关应保证玩家无需广告也能轻松通关。
- 提示道具不要直接消除卡牌，只提供信息，保留核心玩法。
- 双倍奖励广告收益高于普通奖励，但不影响关卡难度。
- 限时/限步模式上线前，先用数据确认普通模式平均用时和步数。
