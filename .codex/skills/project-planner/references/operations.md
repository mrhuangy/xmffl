# 项目测试与维护指南

用于补充 `docs/project-plan.md` 中的测试流程、发布流程和后续维护清单。默认不要创建单独的操作流程文档，除非用户明确要求。

## 可合并内容

根据项目类型，将以下内容合并进项目规划文档：

1. 测试流程
2. 验收标准
3. 发布流程
4. 部署注意事项
5. 数据监控
6. 故障处理
7. 后续维护清单
8. 文档维护要求

## 实用流程

技术栈已知时，写出准确命令：

- 安装依赖
- 启动本地开发
- 运行测试
- 运行 lint 和格式化
- 构建生产资源
- 执行数据库迁移
- 写入本地种子数据
- 部署

如果技术栈还未确定，将命令标记为占位，并说明何时补充。

## 验收标准

每个里程碑建议包含：

- 必须可用的功能
- 如何验证
- 演示场景
- 预计修改的文件或模块
- 已知风险
